# Отчёт по функциям и транзакциям (День 10)

## 1. Созданные функции

| Функция | Назначение |
|---|---|
| calc_discount(price, discount_percent) | считает цену со скидкой, округляет до 2 знаков |
| pluralize_items(count) | склонение слова «товар» (1 товар, 2 товара, 5 товаров) |
| format_full_name(last, first, middle) | «Фамилия И.О.» или «Аноним» |
| place_order(conn, user_id, product_id, size_id, quantity) | создаёт заказ с проверкой остатков и списанием |
| cancel_order(conn, order_id) | отменяет заказ и возвращает остатки на склад |
| get_client_tier(total_spent) | уровень клиента (Новичок … Платина) |
| get_client_loyalty_days(first_order_date_str) | количество дней с первого заказа |

Все функции обрабатывают None и некорректные типы.

## 2. SQL-запросы с функциями

### Запрос 1. Товары со скидкой 20%
Используется `calc_discount(price, 20)`.

### Запрос 2. Клиенты без отчества
Используется `format_full_name(...)` — для клиентов без отчества
возвращается «Аноним» или «Фамилия И.».

### Запрос 3. Проданные единицы в заказе
Используется `pluralize_items(quantity)` — выводится «3 товара» и т.п.

### Запрос 4. Сумма заказа со скидкой 10%
Комбинация `format_full_name` + `calc_discount(SUM(...), 10)`.

### Запрос 5. Аналитика по клиентам
`format_full_name` + `get_client_tier` + `get_client_loyalty_days`.

## 3. Транзакции

- **place_order:** проверяет пользователя, находит stock_item_id,
  проверяет остаток, вставляет заказ и позицию, списывает остаток.
  При любой ошибке — `conn.rollback()`.
- **cancel_order:** находит все позиции заказа, возвращает остатки,
  удаляет позиции и сам заказ. При ошибке — `rollback()`.
