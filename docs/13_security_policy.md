# Политика безопасности (День 13)

## 1. Защита от SQL-инъекций
**Уязвимость:** Использование f-строк для SQL.
**Защита:** Параметризованные запросы с `?`.
**Тест:** `vulnerable_login` с `' OR '1'='1` вернула всех пользователей. `secure_login` вернула 0.

## 2. Хранение паролей
Пароли хранятся в виде SHA-256 хэшей в поле `password_hash`.

## 3. Разграничение прав
Роль `admin_db` имеет полный доступ. Роль `reader` — только `SELECT`.

## 4. Аудит
Таблица `login_audit` логирует логин, статус (успех/отказ) и время.

## 5. Защита файла БД
Рекомендуется `chmod 600 db/shoe_store.sqlite` в Linux.
