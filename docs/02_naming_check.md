# Проверка схемы именования

Документ содержит проверку всех имён таблиц и полей базы данных
«Чудо Обувь» на соответствие правилам именования.

**Правила именования:**
1. Имя начинается с буквы.
2. Имя содержит только латинские буквы, цифры и символ нижнего
   подчёркивания.
3. Имя записано в нижнем регистре.
4. Имя не является зарезервированным словом SQL.
5. Имя таблицы — во множественном числе.
6. Имя поля — в единственном числе.
7. Идентификатор — с суффиксом `_id`.
