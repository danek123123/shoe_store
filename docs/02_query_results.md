## Запрос 4. Список всех заказов с ФИО клиентов (JOIN)

**Что делает:** для каждого заказа выводит дату и ФИО оформившего
пользователя. Использует JOIN между `orders` и `users` — это
первый пример JOIN в проекте.

**Результат:**

| order_id | order_date | client_fio |
|---|---|---|
| 1 | 2026-10-10 10:15:00 | Пользователев Пётр |
| 2 | 2026-10-11 14:30:00 | Менеджеров Михаил |
| 3 | 2026-10-12 09:05:00 | Админов Алексей Алексеевич |

Связь `orders.user_id → users.user_id` позволяет получить ФИО
из таблицы пользователей, не дублируя его в заказах.
