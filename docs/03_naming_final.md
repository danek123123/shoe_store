# Аудит схемы именования (итоговый)

Документ содержит итоговую проверку всех имён таблиц и полей базы
данных «Чудо Обувь» на соответствие правилам именования.

Правила именования:
1. Имя начинается с буквы.
2. Только латинские буквы, цифры и подчёркивание.
3. Имя в нижнем регистре.
4. Имя не является зарезервированным словом SQL.
5. Имя таблицы — во множественном числе.
6. Имя поля — в единственном числе.
7. Идентификатор — с суффиксом _id.

## 7. Автоматическая проверка (Python-скрипт)

Скрипт: `src/db_naming_check.py`
Команда запуска: `python -m src.db_naming_check`

Функции скрипта:

- `get_tables()` — возвращает список таблиц через `sqlite_master`;
- `get_columns(table_name)` — возвращает поля таблицы через `PRAGMA table_info`;
- `check_name(name)` — проверяет одно имя на соответствие правилам;
- `check_database()` — собирает отчёт по всем таблицам и полям.

**Результат проверки:**

|---|---|
| Проверено объектов | 38 |

**Вывод:** все имена таблиц и полей соответствуют правилам
