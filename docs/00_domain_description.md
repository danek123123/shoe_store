# Описание предметной области: «Чудо Обувь»

Торговая компания «Чудо Обувь» занимается продажей обуви и имеет сеть
магазинов. Приложение для заказа обуви даёт возможность клиентам
выбрать и заказать одну или несколько пар обуви из каталога различных
моделей и размеров в торговом зале. На данный момент услуга
предоставляется только для обуви, в дальнейшем возможно расширение
ассортимента за счёт аксессуаров.

## Функциональные требования

1. В каталоге должно храниться актуальное доступное для заказа
   количество товарных позиций — сочетаний модели и размера.
2. Для каждой модели в каталоге должно сохраняться изображение.
3. Пользователь должен иметь возможность выбрать из каталога одну
   или несколько пар обуви доступного размера и модели.
4. В интерфейсе должен быть доступен просмотр списка заказов
   с ключевой информацией: дата заказа, ФИО клиента.
5. Должно быть реализовано управление заказами.

## Пользователи системы

- **Неавторизованный пользователь** — просматривает каталог
  (без фильтрации, сортировки, поиска).
- **Авторизованный пользователь** — просматривает каталог
  (с фильтрацией, сортировкой, поиском), оформляет заказы:
  добавляет/удаляет позиции, изменяет количество.
- **Менеджер** — всё, что авторизованный пользователь, плюс:
  просмотр заказов, состава конкретного заказа, добавление и
  удаление заказов.
- **Администратор** — всё, что менеджер, плюс: редактирование
  заказов.

Вход в систему выполняется только по логину из списка пользователей.
Пароль не требуется.

## Основные сущности

- **Пользователь** — логин, фамилия, имя, отчество, роль.
- **Товар** — категория, подкатегория, производство, наименование,
  изображение, состав, описание, размерный ряд, доступные для заказа
  размеры, количество, цена.
- **Товарная позиция** — модель, размер.
- **Заказ** — дата заказа, ФИО клиента, товарная позиция,
  количество, цена за единицу, итоговая сумма.

Взаиморасчёты осуществляются в рублях.
