# Сопоставление типов SQLite с типами демоэкзамена

Документ связывает типы SQLite, используемые в проекте «Чудо Обувь»,
с типами из списка демоэкзамена и разбирает 12 полей из задания 1.5.

## 1. Таблица сопоставления типов

| Тип SQLite | Тип из демоэкзамена | Комментарий |
|---|---|---|
| INTEGER | INTEGER / INT | совпадает напрямую |
| TEXT | VARCHAR / NVARCHAR | строка произвольной длины |
| TEXT (ISO 8601) | DATE | дата хранится как строка в формате `YYYY-MM-DD` |
| REAL | NUMERIC / DECIMAL | число с плавающей точкой |
| NUMERIC | NUMERIC / DECIMAL | число с фиксированной точностью |

Дополнительно по правилам SQLite:

- В SQLite тип `VARCHAR(n)` / `NVARCHAR(n)` относится к классу `TEXT`
  (динамическая типизация, длина не контролируется строго).
- `DATE` в SQLite хранится как `TEXT` в формате ISO 8601
  (`YYYY-MM-DD`), поэтому прямое соответствие — `TEXT (ISO 8601)`.

## 2. Разбор 12 полей из задания 1.5 демоэкзамена

| Буква | Поле | Назначение | Тип SQLite | Тип из демоэкзамена |
|---|---|---|---|---|
| А | Идентификатор пользователя | PK таблицы `users` | INTEGER | INTEGER / INT |
| Б | Фамилия пользователя | строка с фамилией | TEXT | VARCHAR / NVARCHAR |
| В | Логин пользователя | строка логина, уникальная | TEXT | VARCHAR / NVARCHAR |
| Г | Дата заказа | дата оформления заказа | TEXT (ISO 8601) | DATE |
| Д | Наименование товара | название модели обуви | TEXT | VARCHAR / NVARCHAR |
| Е | Путь к изображению товара | строка пути к файлу | TEXT | VARCHAR / NVARCHAR |
| Ж | Размер обуви | значение размера (возможны 36.5) | REAL / NUMERIC | NUMERIC / DECIMAL (при целых — INTEGER) |
| З | Доступное количество товарной позиции | целое количество | INTEGER | INTEGER / INT |
| И | Цена товара | цена в рублях, возможны копейки | NUMERIC | NUMERIC / DECIMAL |
| К | Количество товара в заказе | целое количество | INTEGER | INTEGER / INT |
| Л | Цена товарной позиции в заказе | цена на момент заказа, копейки | NUMERIC | NUMERIC / DECIMAL |

## 3. Краткий ответ в формате демоэкзамена

```text
А - INTEGER (INTEGER / INT)
Б - TEXT (VARCHAR / NVARCHAR)
В - TEXT (VARCHAR / NVARCHAR)
Г - TEXT ISO 8601 (DATE)
Д - TEXT (VARCHAR / NVARCHAR)
Е - TEXT (VARCHAR / NVARCHAR)
Ж - NUMERIC (NUMERIC / DECIMAL), при целых — INTEGER
З - INTEGER (INTEGER / INT)
И - NUMERIC (NUMERIC / DECIMAL)
К - INTEGER (INTEGER / INT)

М - INTEGER (INTEGER / INT)
```

## 4. Пояснения по спорным полям

### Поле Ж — «Размер обуви»

В предметной области размер может быть числом с половиной (например,
36.5). В этом случае подходит `REAL` или `NUMERIC`. Если по требованиям
размеры только целые — достаточно `INTEGER`.

В проекте «Чудо Обувь» используется **INTEGER** для поля `sizes.value`,
поскольку диапазон задан целыми числами от 16 до 50. Если появится
требование хранить полуразмеры — тип следует заменить на `REAL`.

### Поля И и Л — «Цена товара» и «Цена товарной позиции в заказе»

Цены хранятся в рублях, возможны копейки. Поэтому используется `NUMERIC`
(эквивалент `DECIMAL` в демоэкзамене). Тип `REAL` тоже допустим, но
`NUMERIC` предпочтительнее: он точнее представляет денежные значения.

### Поля А и М — идентификаторы

Идентификаторы пользователя и заказа — это первичные ключи, поэтому
тип `INTEGER` (в демоэкзамене `INTEGER / INT`) с ограничением
`PRIMARY KEY AUTOINCREMENT`.

### Поля Б, В, Д, Е — строки

Все строковые значения (фамилия, логин, наименование, путь к изображению)
относятся к типу `TEXT`, что соответствует `VARCHAR` / `NVARCHAR`
из списка демоэкзамена. Поле «Логин пользователя» дополнительно имеет
ограничение `UNIQUE`.

### Поле Г — «Дата заказа»

В SQLite нет отдельного типа `DATE`, дата хранится как `TEXT`
в формате ISO 8601 (`YYYY-MM-DD`). Это напрямую соответствует типу
`DATE` из демоэкзамена. В проекте используется `DEFAULT CURRENT_DATE`.

### Поля З и К — количества

Целые числовые значения (доступное количество товарной позиции и
количество товара в заказе) — тип `INTEGER`, что совпадает
с `INTEGER / INT` из демоэкзамена.
